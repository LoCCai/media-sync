## 3. Linux 阶段 B 清单

   - OS；

   - filesystem；
   - CPU/RAM；

2. 运行完整套件并保存脱敏 JUnit 摘要。

4. 检查 BUILD-MANIFEST。
5. 执行 deep readiness。

   - 每运行容器一个受管 Xvfb；
   - 空闲零 Chromium；
   - 空闲零 ffmpeg/ffprobe；
   - 无永久 running Job。

## 5. 真增量定义

必须区分：

### 幂等重放

两次运行间上游无变化：

```text
new Content = 0
new Asset = 0
download bytes = 0
export managed changes = 0
```

### 真实增量

通过可控账号发布一个新内容：

```text
new Content = 1（或明确预期）
旧内容无重复
只下载新增 Asset
只更新受影响作者媒体库
```

两份真实响应离线重放只能证明算法，不能单独达到 Supported。

## 8. 支持等级

### Supported

- 真人登录；
- 作者同步；
- 幂等；
- 真增量；
- 媒体下载；
- 归档；
- Emby/网页验证；
- 无未解释 P0/P1。

### Experimental

主路径通过，但存在未验证恢复、媒体形状或非确定兼容性。

### Metadata-only

可获取内容元数据，但媒体资产链未完成。

### Blocked External

账户、地区、平台挑战或上游限制阻塞。

### Unsupported

实现不存在或明确关闭。
