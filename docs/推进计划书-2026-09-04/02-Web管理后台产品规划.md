# Web Console v2 产品规划

> 状态校准（2026-09-04，`38e0ebe` 后）：下方“当前单文件控制台”是 0050 前历史基线。0050 已交付九路由 SvelteKit Console v2、内容/媒体库只读投影与 `/legacy` 回退；仍有效的缺口是持久操作/日志、丰富预览/恢复、媒体服务器联动和操作者鉴权。

## 1. 为什么现有后台需要升级

当前单文件控制台已经能完成最小操作：

- 服务状态；
- 账户创建和扫码；
- 订阅创建；
- scheduler/pipeline 手动运行；
- 任务和操作列表；
- 资产列表；
- Emby 导出。

但现场故障暴露了它不具备完整产品后台所需的能力：

- 只显示 `account_login_configuration_invalid`，看不到 checkout 具体失败项；
- 二维码 404 只能表现为“等待”，不能区分“尚未生成”和“登录已失败”；
- 操作历史是进程内状态，服务重启后消失；
- 任务、同步运行、内容、资产和导出结果分散；
- 没有内容浏览、媒体预览、归档完整性、媒体库树；
- 没有日志中心、错误聚合、支持包；
- 没有设置、代理、存储和 Emby 连接管理；
- 无鉴权情况下却可能发布到所有网卡。

因此 Web v2 的目标不是重做视觉主题，而是把系统状态和归档工作流变成可理解、可追踪、可恢复的操作产品。

## 2. 对 bili-sync-up 的借鉴

bili-sync-up 的 Web 前端采用 SvelteKit/Vite/TypeScript，页面组织包括：

- 仪表盘；
- 日志；
- 视频；
- 视频源；
- 任务队列；
- 设置。

其任务队列还使用实时事件流更新状态，并提供取消操作；日志页包含级别筛选、分页、自动刷新和下载。

media-sync 应借鉴其信息架构和交互语言，但扩展为多平台模型：

```text
视频源        → 平台账户 + 作者订阅
视频          → 内容 + 多种 Asset + 归档 blob
任务队列      → Scheduler Job + SyncRun + Operation + Pipeline Job
设置          → 系统设置 + 平台策略 + 存储 + Emby + 安全
日志          → 脱敏结构化事件 + 支持包
```

## 3. 目标用户

### 3.1 日常操作者

需要：

- 查看今天是否同步成功；
- 哪个平台登录过期；
- 哪些作者有新内容；
- 哪些媒体下载失败；
- Emby 是否已经发布；
- 一键重试安全可重试的任务。

### 3.2 维护者

需要：

- 精确错误码；
- 任务关联链；
- checkout、工具链、代理和存储诊断；
- 构建清单；
- 结构化日志；
- 备份恢复和升级检查。

## 4. 一级导航

### 4.1 总览

展示：

- 服务、数据库、MediaCrawler、Chromium、ffmpeg、存储状态；
- 平台账户：正常、待认证、过期、失败；
- 订阅：启用、暂停、到期、连续失败；
- 任务：运行中、等待、失败、被阻塞；
- 内容和资产新增数量；
- 归档总容量与最近增长；
- Emby 待发布、发布失败和最近成功；
- 最近五个高优先级错误。

总览的每个卡片必须可下钻，不能只是数字。

### 4.2 平台账户

按平台卡片显示：

- 显示名；
- 登录方式；
- 当前 auth 状态；
- 浏览器 profile 是否存在；
- 最近认证时间；
- 会话过期时间；
- 最近登录尝试；
- 预检结果；
- 重新认证入口。

### 4.3 作者与订阅

列表和向导：

- 平台；
- 账户；
- 作者 ID/主页 URL；
- 显示名；
- 采集间隔；
- 单次上限；
- 请求延迟；
- headless；
- 全历史确认；
- 状态、下次运行、上次成功；
- cursor/水位摘要；
- 最近运行与最近错误。

### 4.4 任务中心

统一展示：

- Scheduler Job；
- SyncRun；
- Pipeline Job；
- Asset download；
- Emby export；
- 登录 Operation；
- 备份/恢复/升级 Operation。

支持按状态、平台、账户、订阅、作者、任务类型和时间筛选。

### 4.5 内容

支持：

- 卡片和表格视图；
- 平台、作者、发布时间、类型、是否有媒体筛选；
- 正文摘要；
- 封面；
- 互动字段；
- 原始来源链接；
- 相关 Asset；
- 是否已完整归档；
- 是否已导出。

### 4.6 资产与归档

展示：

- kind、position、MIME、大小、摘要；
- generation；
- 下载状态；
- locator 类型的脱敏摘要；
- 归档 blob 是否存在；
- ffprobe 摘要；
- 可重试性；
- 下载/校验；
- 强制重下载仅在未来具备 fenced generation 后开放。

### 4.7 媒体库

树形展示：

```text
作者
  └─ 年份/季
      └─ 内容/集
          ├─ 主视频
          ├─ 多分 P
          ├─ 海报/背景
          ├─ 图集
          ├─ NFO
          └─ 来源信息
```

并显示：

- 当前 source fingerprint；
- published tree fingerprint；
- 是否需要重新导出；
- Emby/Jellyfin 最近扫描；
- 抽样播放资格。

### 4.8 日志与诊断

- 结构化日志；
- 实时追加；
- 级别、模块、任务、错误码筛选；
- 固定错误码说明；
- checkout 预检；
- 工具链预检；
- 支持包导出；
- 严禁原始 Cookie 和签名 URL。

### 4.9 设置与运维

- 基础路径只读展示；
- 采集默认值；
- 平台速率限制；
- 代理；
- Emby/Jellyfin 连接；
- 日志保留；
- 备份与恢复；
- 升级前检查；
- 构建清单；
- 安全状态。

## 5. 关键交互

### 5.1 登录流程

```text
点击登录
  → 自动执行深度预检
  → 显示每项检查
  → 通过后启动登录 child
  → 显示二维码与倒计时
  → 展示状态变化
  → 成功后立即刷新账户
```

失败时显示：

- 固定错误码；
- 失败阶段；
- 可否重试；
- 修复说明；
- 关联操作 ID。

### 5.2 任务详情抽屉

至少包含：

- 任务 ID；
- 自然键；
- 状态；
- attempt/max attempts；
- lease owner 和过期时间的安全摘要；
- phase；
- progress；
- 关联账户、订阅、内容、资产；
- 最近事件；
- error code；
- retryable；
- 允许的动作。

### 5.3 破坏性动作

删除订阅、清理工作目录、重置 generation、恢复数据库等必须：

- 二次确认；
- 显示影响范围；
- 使用幂等键；
- 持久记录操作者动作；
- 不允许浏览器刷新导致重复提交。

## 6. 首页样式建议

采用类似 bili-sync-up 的清晰侧栏与卡片式布局，但不要堆积大图表。优先展示：

- 状态；
- 下一步动作；
- 阻塞；
- 失败；
- 容量；
- 最近新增。

图表仅用于：

- 每日新内容；
- 下载字节；
- 失败趋势；
- 平台分布；
- 存储增长。

## 7. 产品验收标准

- 新操作者无需 CLI 即可完成账户、订阅、同步、下载和导出；
- 任意失败最多两次点击可找到固定错误码和关联对象；
- 服务重启后历史仍在；
- 页面可在桌面和手机上操作；
- 无网络时静态页面仍可打开并显示服务不可达；
- 页面不展示机密、签名 URL、完整 Cookie 或浏览器 profile 内容；
- 所有 API 状态和文案与领域状态机一致；
- Web 操作和 CLI 操作调用同一 application service。
