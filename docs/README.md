## Documentation rule

Before a milestone starts, create its `goal.md`/`plan.md` (English) and `goal.zh.md`/`plan.zh.md` (Chinese). During implementation, update `progress.md` and `progress.zh.md`. Before committing, record exact commands, exit codes and important output in `verification.md` and `verification.zh.md`. Keep both language editions structurally identical and in lockstep: neither edition may claim something the other does not, and the language-switcher link must point to the counterpart file. The one-shot migration tool for the former mixed-language layout is [`scripts/split_bilingual_docs.pl`](../scripts/split_bilingual_docs.pl). Secrets, cookies and personal account data must never be copied into these records.
