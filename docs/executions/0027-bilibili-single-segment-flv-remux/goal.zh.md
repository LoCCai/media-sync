## 验收边界

- 继续要求精确一个 `durl` 分段；不声明支持多段、拼接及逐段顺序/大小语义。
- FLV 只由封闭的顶层播放格式契约识别；URL 后缀、响应 MIME 与下载字节均不能授予 FLV 权限。
- 源必须结构化探测为 FLV 视频，成品必须结构化探测为 MP4 视频；不允许转码、编码修复、字幕/弹幕嵌入或原始 FLV 降级发布。
- 源与成品共用既有 Asset 字节上限与截止时间；ffmpeg 输出有界、参数固定且不经过 shell。
- 不计划数据库 schema 或 migration；稳定 Asset 身份与十二个冻结媒体形状计数均不变化。
- `.upstream` 继续只读且不纳入跟踪。
