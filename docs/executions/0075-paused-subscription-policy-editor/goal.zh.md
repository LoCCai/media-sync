# 目标：暂停态订阅策略编辑

状态：**已在 `aec3eac` 完成本地实现**。本执行未包含部署或真人平台操作。

执行 0075 补齐 0074 B 站耐久交付之后的操作者策略编辑。已有 MediaCrawler 订阅可以先暂停、编辑、核对并重新启用，无需删除检查点、交付证据、内容、归档字节或已发布媒体库目录。

## 必须实现的行为

1. 只有未删除、已暂停且空闲的 MediaCrawler 订阅可编辑。存在待处理 Job、非终态 SyncRun 或活动订阅操作时拒绝修改。
2. 每次编辑必须携带精确当前 `expected_schedule_revision`。过期请求不修改任何状态；真实变化只增加一次修订；完全相同的重放不增加修订。
3. 可编辑集合封闭为同步周期、单次条数上限、上游请求间隔、浏览器无头模式及 B 站采集范围。既有全历史确认和不透明作者秘密引用必须原样保留，且绝不返回。
4. B 站 `dynamics` 与 `both` 继续要求至少两条；非 B 站订阅不能接收 B 站范围。
5. 编辑事务不改写 cursor、backfill cursor、checkpoint revision、水位、扫描证据、B 站交付证据、失败计数、`next_run_at`、历史行、归档字节或媒体库文件。影响 B 站交付绑定的变化由既有逻辑在下一轮重新取得资格。
6. REST、CLI 与 Web 共用同一个应用服务和固定安全错误码。响应只返回白名单策略摘要及稳定计数，不暴露凭据、locator、上游响应或宿主路径。
7. Web 详情页从刚读取的订阅修订初始化；订阅启用或已删除时编辑器保持禁用；客户端校验返回身份与修订；被拒绝后不自动恢复订阅，也不自动重放修改。

## 验收证据

- SQLite 及 PostgreSQL 兼容事务测试覆盖暂停/启用/删除、过期修订、精确 no-op、并发写入、活动 Job/Run/operation 栅栏、损坏现有策略，以及秘密和检查点保留。
- API 与 CLI 测试证明封闭请求/响应词汇及脱敏边界。
- Web 测试覆盖 payload/响应校验、固定失败文案、过期请求取消、平台范围规则和页面接线。
- 浏览器渲染流程证明：订阅详情 → 暂停态策略编辑 → 保存 → 策略更新且仍暂停，并且没有相关控制台错误。
- 记录专项及完整 Python/Web 门禁、格式、类型、构建、文档链接、上游锁和制品构建结果。

## 明确不做

- 编辑凭据、作者身份、本地备注、全历史确认、输出目录、重试策略或调度 lane 策略。
- 把取消任务、恢复订阅、启动采集、下载、导出或媒体服务器访问作为编辑副作用。
- 在本执行加入其他平台的耐久分页语义。本编辑器完成后从 XHS 开始逐平台审计，不能复制 B 站 cursor 假设。
- Docker/Linux 部署，以及真人账户、平台、CDN、宿主媒体库或 supervisor 资格。
