# 进展：暂停订阅现在有一个修订栅栏策略编辑器

状态：本地实现已在 `aec3eac` 完成。Docker/Linux 部署、真实 PostgreSQL 竞态及真人平台资格仍待执行。

## 结果

已有 MediaCrawler 订阅现在可通过一个封闭流程修改：

```text
新鲜订阅详情
  -> 未删除 + 已暂停 + 空闲检查
  -> 精确调度修订比较
  -> 一次原子策略更新
  -> 订阅仍暂停，断点、历史和媒体均保留
```

七个平台的 MediaCrawler 订阅都共用同步周期、单次上限、请求间隔及浏览器模式四项通用控制。只有 B 站有第五项采集范围；小红书、抖音、快手、微博、贴吧和知乎不能收到该字段。这只是策略编辑能力，不代表这些平台已有耐久分页或真人增量资格。

## 已实现

1. **单一事务所有权。** 应用服务预占 SQLite writer，或锁定精确 PostgreSQL 订阅行；修改前在事务内复核活动 Job、非终态 Run 及活动 operation。
2. **封闭原子修改。** 同步周期、单次上限、上游间隔、无头模式及可选 B 站 scope 在 `expected_schedule_revision` 下整体更新。真实变化只递增一次，完全 no-op 不消耗修订。
3. **精确保留。** 全历史确认和不透明作者引用在封闭策略中原样保留；cursor、backfill cursor、checkpoint、水位、时间、失败及 `next_run_at` 字段均不改写。既有扫描/交付/历史/媒体权威留在原位；影响交付绑定的 B 站变化只在后续周期物化时重新取得资格。
4. **控制面共用服务。** `PUT /api/v1/subscriptions/{id}/policy`、`media-sync subscription policy` 与 Web 编辑器全部调用同一服务。请求拒绝额外字段；响应和错误只用固定白名单，不含秘密引用、locator、上游正文或宿主路径。
5. **通用暂停态编辑器。** 旧 B 站单项 scope 卡片已替换为结构化策略编辑器；启用、删除、策略损坏及忙碌状态都会解释为何不能保存。成功后订阅保持暂停，并明确本次没有启动采集、下载或导出。
6. **过期响应栅栏。** 浏览器请求绑定订阅身份、平台、精确修订、操作者 session epoch、弹窗生命周期和单个在途 generation。保存期间不能关闭弹窗，被取消或迟到的响应不能转成成功。
7. **操作者反馈。** 无效周期和字段范围有明确提示；固定失败可前往任务页、重读详情或查看已删除订阅，且不会自动重放修改。

## 审查修正

- REST 请求间隔字段现在拒绝字符串隐式转换，只接受严格 JSON 数字。
- 应用层直接收到不可哈希或跨平台 B 站 scope 时，固定返回 options 错误，不再可能触发内部 `TypeError`。
- 最终 Ruff format 移除了测试中的一行多余空白；没有行为变化。
