# 目标

交付用户要求的粘贴Cookie登录：操作者提供浏览器Cookie请求头，服务校验远端已认证数据，仅在候选成功后私密保存并供后续采集复用；失败必须保留原有效凭据。七平台登录/订阅/采集/归档/本地Emby/Jellyfin输出的整体目标不变。

基线：`68c4004`。上一目标轮分类为进展：0057已实现发布，有最终回归及fresh-fetch一致性证据。本执行处理明确接受的Cookie需求，不重新判定生产失败金丝雀。

源码审计支持B站、小红书、微博、知乎的有界本人资料验证。锁定抖音/贴吧pong仅判断本地标记；快手仅GraphQL result成功缺少已认证与匿名的区分证据。后三平台仍必需完成，在可靠远程证据实现前必须明确不可用。合成测试不授予真人资格。
