# 冻结计划

基线 HEAD=origin/main `5948b91`，工作区干净。上一目标轮已完成0066实现/发布，属于经验证的推进，不是等待。本阶段不操作生产。

1. 新增数据库持久化单例输出策略，含 CAS 修订、绝对总根、布局模式和七平台可空覆盖。文件写入前持久化作者的不可变输出绑定。API/CLI/supervisor 读取同一数据库策略，不依赖启动时环境快照。没有旧输出的新库默认平台子目录；初始化既有库保留旧平铺目录，不静默改名。
2. SQLite 和 PostgreSQL 使用真实并发控制，保护初始化和策略修改。保存不创建目录、不搬移/删除/重写文件；已有发布或绑定的平台根未经显式迁移不能改，返回固定冲突及受影响平台。其它平台、继承/显式根仍可编辑。这是保护边界，不代表文件迁移已实现。
3. 校验原生绝对本地路径、长度、非盘符/系统根、平台有效根互不嵌套（旧共享平铺例外）、状态/归档/任务/凭据/运行时/源码保护根；逐个检查现有祖先的符号链接和reparse。使用前复验；下载/检查接口不接收任意请求根。平台来自数据库身份，已有作者绑定跨策略修订保持稳定。
4. 正常及手动输出写入、当地库检查全部接共享服务。写入执行时先绑定再发布，防止并发保存改向在途或可重试工作。私有归档预览不变。新平台布局不能复用过时的单根媒体服务器映射；仅保持精确旧映射或明确要求配置，不猜测服务器路径。
5. 增加已认证、CSRF保护的输出设置 GET/PUT 和预览，固定安全错误/CAS冲突，不开放通用配置修改。设置页展示总根、平台覆盖/生效路径、旧目录保护及跨进程持久化，明确容器路径和宿主机挂载、私有归档不变、两个服务挂载一致。
6. 验证迁移、初始化/CAS竞争、七平台继承覆盖、路径拒绝、旧根、在途/已绑定冲突、真实API保存至独立supervisor执行及兼容文件、本地检查、零工作重放、无需服务器。不自动生产登录/下载/部署/恢复supervisor，如实记录失败和未运行项。
7. 保存双语目标/计划/推进/验证，运行受影响后端/前端/静态/文档/锁定/构建及复核，双语提交并正常推送核对GitHub一致。不因设置能保存就声称历史下载闭环完成。

分工：存储代理负责策略模型/迁移/服务/安全测试；运行代理负责流水线/CLI接线及测试；主代理负责API/前端/文档和联合验证；独立复核负责旧位置与媒体服务器兼容。
