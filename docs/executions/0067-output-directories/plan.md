# Frozen plan

Baseline HEAD=origin/main `5948b91`; clean worktree. Previous goal turn made verified progress (0066 implementation/publication), not a wait. No production actions this milestone.

1. Add a database-persisted singleton output policy with CAS revision, common absolute root, layout mode and seven nullable platform overrides. Persist per-author immutable output bindings before file writes. API/CLI/supervisor resolve the same database policy, not a startup-only environment snapshot. Fresh unpopulated libraries default to platform subdirectories; preserve existing legacy flat output on initialization rather than silently renaming it.
2. Guard initial creation and policy updates with real database concurrency control for SQLite and PostgreSQL. Saving changes neither creates directories nor moves/deletes/re-publishes files. Existing published or bound platform roots cannot change without explicit migration; return a fixed conflict with affected platforms. Unaffected platforms and inherited/explicit roots remain editable. This protective boundary is not a completed file-migration feature.
3. Validate native absolute local paths, bounded strings, non-root targets, disjoint effective platform roots (legacy shared-flat exception), protected state/archive/job/secret/runtime/source roots, and every existing ancestor for symlinks/reparse points. Validate again before use. Never accept arbitrary request-provided roots in a download/inspection endpoint. Resolve platform from database identity. Existing bound roots keep jobs stable across policy revisions.
4. Wire every supported normal/manual output writer and local inspection reader through the shared service. Bind on writer execution before publication, so concurrent Save cannot redirect active or retryable work. Private archive previews remain unchanged. New platform layout must not reuse a stale single-root media-server mapping: preserve only the exact legacy mapping or explicitly require configuration; do not guess remote paths.
5. Add authenticated, CSRF-protected GET/PUT output settings and preview support using fixed-safe errors, CAS conflict handling and no generic configuration mutation. Build a Settings form showing common root, per-platform override/effective path, legacy protection and restart-independent policy persistence. Explain container versus host mounts, unchanged private archive and identical mounts for API/supervisor.
6. Test migrations, initialization/CAS races, seven-platform inheritance/overrides, path rejection, legacy roots, active/bound output conflicts, real API save→independent supervisor execution→compatible files, local inspection, zero-work replay and no-server use. No automatic production login/download/deployment/supervisor recovery. Record actual failures and environment NOT_RUN.
