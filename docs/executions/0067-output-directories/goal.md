# Goal

Make compatible media-output directories editable: a common root with platform subdirectories and optional per-platform roots, shared by API and resident supervisor. Private content-addressed archives, state, jobs, credentials and browser profiles remain unchanged. The normal subscription workflow writes compatible files automatically without an Emby/Jellyfin connection or manual export.

This advances the full seven-platform goal; real login/capture, permanent historical completion, incremental updates and explicit migration of existing published libraries remain required where not yet proven.
