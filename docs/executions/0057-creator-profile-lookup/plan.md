# Frozen implementation plan

Baseline: `87ef7fd`. Commit this plan before protocol/schema changes. Keep the upstream versions pinned by upstreams.lock.json.

1. Add a separate Bili saved-session runner permitting only noninteractive authentication/WBI setup and one client.get_creator_info(mid). Forbid core.get_creator_details, content/dynamics/comments, QR fallback and login-state promotion. Preserve private stdin, closed result frames, origin checks, the shared account file lock and parent-death/full-child-tree cleanup. Share a 45-second execution budget including preparation across all steps, plus at most 15 seconds for cleanup; never release the lock before confirmed tree exit or claim a strict 45 seconds including OS cleanup.
2. Add account/platform/creator-scoped CreatorProfile and exact Operation lookup records. Monotonic backend generation binds a frontend_generation UUID, operation_id and credential snapshot. Increment Account.auth_revision on authentication changes to fence equal-time and A→B→A changes without hashing active browser files. Begin/publish share one transaction with Operation lease, expiry and cancellation checks. Failures/late responses never clear prior successful profiles.
3. Add Subscription.local_alias, migrating existing author labels as local notes, not remote facts. Creation/replay must not rename an existing Author or change its URLs/export paths. New API input can reference profile_lookup_id for server-held data from a successful, exact-identity/version Operation within 15 minutes; never trust client assertions of remote nicknames. Retain legacy display_name as local-note compatibility. New local_alias is optional when a valid profile receipt exists.
4. Operation kind is creator-profile, targeting account. POST /api/v1/accounts/{account_id}/creator-lookups accepts closed platform, creator_remote_id, frontend_generation, enable_mediacrawler and accept_mediacrawler_license, returning the existing operation-start shape. GET /api/v1/creator-lookups/{operation_id} returns closed operation state, exact lookup identity and profile projection; lookup may be null during preparation. Operation/SSE stores only fixed codes, UUIDs, counts and digests, never nickname/URL/credential text. Preserve authentication/CSRF and license consent.
5. Freeze Bili HTTPS avatar hosts/paths; do not fetch unknown shapes. No cookies/auth/environment proxies, no redirects, public DNS/connection pinning, 2 MiB input, eight million pixels, single-frame JPEG/PNG/WebP, bounded fetching and isolated PNG re-encoding. Replace the draft file cache with bounded database binary storage to remove arbitrary cache-path exposure; at most 2 MiB, independent revision/observed_at. Authenticated same-origin /api/v1/creator-profiles/{profile_id}/avatar/{revision} accepts no arbitrary URL and does not weaken CSP. Nickname success/avatar failure preserves and labels the older avatar.
6. On completed stable input (blur/Enter), the UI automatically queries once per identity generation, not per keystroke and without infinite retries. Lookup is independent of full-history consent, crawl options and local alias. Show nickname, optional note, remote observation time, errors and retained-avatar state. Fence identity/session/operation/request/image-load races. Explicitly label unsupported platforms/non-saved-session rather than claiming remote validation.
7. Parallel ownership: runner/contracts; DB/migration/alias/races; Web/race tests; root owns Operation/API/avatar/integration. Verify exact profile call counts and forbidden-method traps, expired auth without QR, shared-account/tree cleanup, lease/cancel/auth ABA/generation fencing, account isolation, migration/path preservation, avatar SSRF/size/decode, API auth and frontend late responses. Record failures, fixes, skips and unrun gates. Bilingual commits, non-force push and fresh-fetch verification.

This increment does not authorize production deployment/login/subscription mutations/capture retries/download/export/supervisor restart. Pasted-Cookie private validation/storage, six-platform profiles, correct bounded coverage and live capture/archive/media-server qualification remain mandatory.
