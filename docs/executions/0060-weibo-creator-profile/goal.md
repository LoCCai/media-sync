# Goal

Extend automatic, authenticated creator nickname/avatar lookup from Bili to Weibo for saved-session and pasted-Cookie accounts. A completed stable numeric UID entry should obtain platform-observed identity, with an optional local alias; it must not crawl posts, rename existing archive paths, or require a media-server connection.

Baseline `1b9b516`, freshly fetched, clean and divergence 0 0. Execution 0059 is published and already verified; its full test results are not rerun or inherited as this slice's proof. The seven-platform login/subscription/text-image-video/archive/local Emby/Jellyfin objective remains active. The other five profile adapters, remaining Cookie validators, Bili dynamics and live end-to-end qualification remain required.
