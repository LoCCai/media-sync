# Execution 0001 goal

Create a trustworthy project baseline before implementation: inspect the empty workspace, fetch both requested upstream projects, pin exact revisions, identify license constraints, establish durable documentation conventions, and produce the first local Git commit.

## Acceptance

- Both upstream HEADs resolve to recorded SHA values.
- `.upstream/` is excluded from the new repository.
- Goal, plan, progress and verification records exist.
- Roadmap and upstream-boundary ADR are reviewable.
- Git working tree is clean after a bilingual commit.
