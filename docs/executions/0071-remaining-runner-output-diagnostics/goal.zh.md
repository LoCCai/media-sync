# 目标：剩余 runner 的安全输出诊断

把执行 0070 的安全分片进程输出诊断扩展到其明确延后的独立隔离路径：粘贴 Cookie 校验、创作者资料查询、内容 detail／媒体地址解析，以及经新一轮进程盘点确认能够安全提供证据的 download／probe／remux／头像 helper 边界。全部保留证据继续写入现有受管 JSONL 分片，使失败可精确关联，同时不创建原始输出归档。

这里仍是选择性的诊断捕获，绝不是文字实录。原始 Cookie 或 Authorization 值、二维码载荷或图片、签名 URL、上游 JSON/JSONL、HTML/DOM、请求或响应正文、创作者元数据、媒体字节及私有文件系统路径绝不能持久化。协议 stdout、带帧结果、ffprobe 输出与头像 PNG 字节继续作为业务通道，而不是日志。进程内 HTTP、DNS 与文件流没有可捕获的子进程输出，只能发出不含正文或媒体内容的闭集生命周期事件。

本执行从仓库基线 `571f993` 开始。它不会部署当前编辑树、重启 supervisor、重试真人平台操作、读取生产凭据，也不会声称扫码已修复。旧版本已丢弃的输出无法恢复；只有部署本版本并另行授权执行操作后，才会产生新诊断证据。

## 验收标准

1. 复用执行 0070 的 `state_dir/logs` store、闭集 `process_output` 事件族、脱敏策略、单次 4 MiB／4096 行／每行 64 KiB 限制、轮转、保留、容量及受管路径防护。不创建其他日志 sink，也不以捕获“全部”第三方文字为由放宽分类器。
2. 接线前冻结明确的信任与进程盘点。Cookie／资料 guardian 与 worker 的长度帧 stdout、detail 结果 stdout、ffprobe stdout 及头像 PNG stdout 继续只承载协议或二进制。Cookie／资料 guardian 的 stderr 当前是无人读取的 pipe，不能把它改成诊断传输通道或可能阻塞的额外写入端。
3. 仅按需要泛化当前进程 fd 捕获及安全的单诊断流排空。发出结果帧或 PNG 前必须恢复描述符并结束捕获。捕获启动、排空、过滤、摘要或 sink 失败不得改变 runner 返回值、权限判断、重试分类、期限、取消或进程树清理。
4. 只在 Cookie worker 远程校验及创作者资料 worker 平台查询周围捕获安全可分类诊断。已知 Cookie 与含秘密的创作者引用只能在内存中提供给脱敏器。guardian 协议及资料结果对象均不得作为日志文字持久化。
5. detail 诊断只能围绕解析精确内容及媒体 locator 的 child 执行捕获，随后先恢复协议 stdout，再发出有界结果帧。原始 detail 行、创作者／内容字段和签名媒体地址绝不进入事件或摘要。
6. 下载路径仅在精确 asset-download 身份存在后，为进程内 HTTP／DNS／文件工作发出闭集生命周期证据。对于盘点出的 ffprobe／ffmpeg probe、mux、remux 与 concat 进程，只捕获策略允许的 stderr，stdout 继续专供解析器。头像 worker 只捕获取回／解码诊断，并在写入 PNG 字节前恢复 stdout。
7. 事件只能绑定经过校验的规范本地身份：Cookie／资料 Operation 与账户、detail 的账户／订阅／平台及可用 asset 上下文，以及权威应用边界创建的下载 Job／asset 身份。跨进程 envelope 只能增加闭集规范 UUID；出现额外、畸形、混合或非规范字段时整体拒绝传播值。直接或不可信方式调用 runner 时保持静默。
8. 已鉴权日志 API 与中文日志中心继续只展示已校验的安全 message、摘要及固定丢弃原因。确定性对抗测试及真实子进程测试证明协议字节精确隔离、guardian 不死锁、关联精确、秘密／正文／媒体在已校验事件与受管分片原始字节中均不存在，并证明日志不可用时业务结果不变。准确记录专项及全仓门禁；除非真实执行，否则 Linux、真人平台及扫码资格保持 `NOT_RUN`。

## 延后但不改变

- 完成版本部署后，必须另行授权并受控执行操作，才能使用新增证据选择平台修复。这项可观测性工作本身不会修复扫码、Cookie 接受、平台行为、下载或播放。
- 对没有精确持久任务身份或已经丢弃输出的 checkout／prefetch／readiness helper，继续维持现状；除非后续盘点与威胁复核证明安全需要，不能仅因存在子进程就扩大捕获。
- 继续七平台订阅、历史回填、风控友好下载、增量同步及 Emby/Jellyfin 兼容目录目标。本轮诊断只提供证据，不能替代或缩减产品主线。
