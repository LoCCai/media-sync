# 安全后台与启动目标

- 日期：2026-09-05
- 基线：`2e1949f`
- 状态：实现前冻结

在不降低鉴权要求的前提下恢复可用的单操作者后台，并在容器启动修改数据库前拒绝无效操作者配置。遵循[交付优先级](../delivery-priorities.zh.md)，七平台产品目标不变。

验收：未登录入口和已知深链接进入登录；只有 session 初始化成功才挂载私有页面；Cookie 写请求注入仅内存 CSRF；退出、过期与迟到响应不能复活私有视图。二维码、直接媒体与 SSE 只使用同源 Cookie，URL 不含凭据。以最终镜像用户运行的仅配置检查复用 serve 的 secret/origin 校验，不构造 app／数据库、不绑定端口、不迁移，且只输出固定安全结果；serve 入口在 Xvfb 和 db init 前先执行此检查。

本增量不做播放确认 UI、证据扩展、真人账户／服务器访问、新平台／媒体形状或架构重写。Legacy 保持鉴权但改为明确迁移提示；没有 v2 build 时根页面提示构建／CLI，不再回落到不可用的交互旧客户端。最终 Linux 镜像与真人金丝雀验收仍须执行 0047 的实际证据。
