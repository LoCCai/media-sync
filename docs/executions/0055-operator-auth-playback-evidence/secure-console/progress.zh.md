## 已交付

上一检查点 `2e1949f` 已发布至 `origin/main`。本次八份双语基线先提交为 `714c849`；所有父级/子级冻结 goal/plan 保持不变。

1. `serve --check-config` 复用真实配置、秘密、Origin、绑定语法检查，输出固定安全结果，不创建应用/数据库/目录，不绑定端口、不迁移。容器 serve 在 Xvfb 和 `db init` 前预检，包括 Click 的 `-- serve`；显式 help/check-only 不初始化状态。
2. 新增后台登录/会话/退出界面，串行执行会修改 Cookie 的请求；登录后必须获取 session/CSRF。凭据/CSRF 只留内存，私有组件树按会话代次、过期、退出控制；退出未确认保持锁定，迟到响应不能恢复新界面。
3. 业务与二维码请求使用同源 Cookie、不安全请求 CSRF、取消及 204 处理，不自动重放写操作。SSE 先关闭再检查会话后降级。当前会话 HTTP 401 即使正文损坏或卡住也立即锁定。
4. 仅八个精确 HTML GET/HEAD 深链接获得中间件匿名登录 303；Host 拒绝仍在最前，API/未知/编码别名仍拒绝，丢弃任意查询，不扩大匿名白名单。
5. 受保护旧 UI 改为无交互双语迁移提示，缺少 v2 构建时给出构建/CLI 指引；认证后首次引导支持只留内存的“稍后确认，仅浏览”，不接受 MediaCrawler 许可证。
6. 真实浏览器发现并修复 Jobs 事件流文案不更新、延迟认证挂载后资产/内容未首次加载；导航查询去重，卸载取消请求。
