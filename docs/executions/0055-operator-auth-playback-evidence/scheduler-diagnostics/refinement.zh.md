# 实施前安全补充

此补充保留原计划，实施前提交。复核在新诊断的精确边界发现两个既有控制/展示缺口。

- 心跳与 handler 清理隔离同时失败时，取消等待 helper 会吞掉 SchedulerLeaseLostError（含清理隔离子类）。在通用 Exception 之前传播该特定隔离异常，避免丢失租约/清理权威后仍用诊断收尾；测试同时失败及 handler 已结束分支，保留普通异常/取消清理语义，不重试或改写 Run。
- Job 详情现在直接渲染 Object.entries，并接受未绑定身份的迟到请求。改为既有 Job 字段白名单及明确清洗的新错误字段；拒绝不匹配的 Job 身份，复用详情请求代际，未知字段/异常不回显。这是把诊断绑定请求 Job 的必要修正，不扩展到其他浏览页。

API 诊断字段仍是可选增加，Operation 摘要及生产数据不变。主代理负责 API/CLI 共用投影测试，worker 子代理负责 service/policy/控制回归，独立数据库子代理负责实际争用测试，Web 子代理负责 Job 展示与精确请求测试。
