## 已实现

- 增加经鉴权作者证据 GET，严格校验规范 UUID 与查询参数，历史默认 20 行、最多 50 行；仅返回本地 ID、时间戳与安全状态。
- 新鲜权威检查在一个有界外部工作 deadline 内完成，然后才打开短数据库读取事务。远端失败、不完整、歧义或权威变化使历史为 unknown 且不能 PASS；完整不存在使历史为 stale。
- 精确当前证据独立于历史查询，最多物化 `limit + 2` 行，不 COUNT、不写入。62 行真实 SQLite 夹具证明最早的当前证据即使超出最新历史页也仍然可见。历史分页截断不否定独立验证的当前证据；远端 lookup 截断则否定。
- 资格 schema v3 只评价显式选定的作者；不指定作者时为 `not_requested`，不查询证据或远端。Scoped PASS 表达精确持久人工确认，不代表播放遥测或整个平台资格。
- 更新 Web 响应类型、59 路由鉴权清单、测试与双语当前文档；未新增 migration 或前端交互。
