# 登录集成后续计划

- 日期：2026-09-05
- 状态：实现前冻结

1. 记录操作者 Linux 冒烟及浏览器只读观察，不保存私人网址、完整账户/会话标识、Cookie 或日志；保留现有冻结计划。
2. 用锁定公开依赖确认 PyExecJS 启动选择；最终容器安装 Debian Node.js，不引入 pnpm/Web 构建工具，并记录运行版本。既有隔离 Python doctor 增加有界固定 JavaScript 算术执行，不导入上游、不访问平台/凭据/profile、不自动接受许可。保留固定安全错误码及现有子进程超时/环境。
3. 规范化上游二维码：兼容有界字节输入，接收严格有界 base64 和明确允许的 base64 位图 data URI，拒绝 URL、畸形/超大载荷及其他类型。不抓取网址、不启动图片查看器，保留原子受限写入、权限、生命周期清理和转发失败不影响登录的语义，不记录输入。
4. 使用假浏览器/网络边界执行锁定二维码 helper 契约，补规范化/脱敏/大小及 doctor 依赖测试。审查 Docker 接线；本机没有 Docker，镜像构建仍由操作者执行。
5. 与正在实现的登录诊断合并，运行相关 Python/Web/质量门，记录实际失败及重跑，显式双语 Git 提交和推送。请求新镜像 doctor 与单账户人工扫码结果，验收前保留真人失败/未知。
