# Goal

Respond to the operator's failed QR logins without disturbing authenticated accounts, and make subscription-driven automatic local delivery the product workflow. The seven-platform goal remains active.

The accepted workflow is: subscribe to a creator → scheduled, resumable historical discovery → paced downloads and compatible directory writes → periodic incremental discovery. Emby/Jellyfin connection and a separate manual export action are not prerequisites. Support a shared output root with platform subdirectories and per-platform overrides in subsequent implementation.
