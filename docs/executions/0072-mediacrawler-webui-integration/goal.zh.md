# 目标：在认证边界内集成锁定的 MediaCrawler WebUI

执行 0072 调整交付顺序：暂停执行 0071 对自定义 runner 输出诊断的继续扩展，改为把已经锁定的 MediaCrawler WebUI 集成为面向操作员的采集入口。这只是优先级转向，不代表 0071 已完成；缺失的诊断覆盖、旧版已丢弃的输出及此前未验证的平台行为都不能因此被重新描述为已解决。

直接复用锁定上游已有的 WebUI、采集控制、登录、采集及媒体下载流程，不在第二套 media-sync UI 中重复实现，也不维护锁定 checkout 的 fork。在这条集成边界中，media-sync 刻意保持轻薄：只负责认证壳、Subscription 调度、任务监视、受控产物摄取，以及确定性的 Emby/Jellyfin 文件夹和 NFO；交互式采集操作与上游媒体网络传输继续由 MediaCrawler 负责。

第一批交付有意小于完整集成：只建立认证后的 `/crawler` 路由、固定且经过校验的 MediaCrawler 虚拟环境、单一受限输出根、上游媒体下载开关、最小浏览器二维码 relay 及专项离线测试。后续批次可在这些已冻结接缝上连接调度运行、完成态摄取与媒体库发布，不以此为由重启 0071 的日志扩展。

## 验收标准

1. **状态表述准确** —— 在交付顺序中把执行 0071 标为暂停，不得把其中部分完成的诊断工作描述为已完成、已部署或已验证。执行 0072 不会重建已丢弃日志，也不会仅因更换集成入口就修复平台问题。
2. **上游继续锁定** —— 使用 `upstreams.lock.json` 记录的 commit 与许可证，不编辑锁定 MediaCrawler checkout 内的文件。运行时只使用一个已配置虚拟环境的 Python 与已校验 checkout；不得回退到环境中的 `python`、`uv`、`PATH` 包或未经校验的 clone。
3. **只有一个经认证的采集入口** —— 在 media-sync 的 `/crawler` 边界下提供上游 WebUI 及其必需的 HTTP/API/WebSocket 控制路径。每个采集页面和控制请求都经过 media-sync 操作员认证；未认证用户不能访问备用上游端口或绕过路由。路由前缀、静态资源和 WebSocket 行为必须经过测试，但不把 WebUI 重写成 media-sync 自有功能。
4. **职责保持收窄** —— MediaCrawler 负责交互式配置、登录、启动／停止／状态、采集及上游媒体下载；media-sync 只负责认证、持久 Subscription 调度、任务观察、从指定输出根摄取产物，以及发布 Emby/Jellyfin 兼容文件夹／NFO。本执行不增加并行登录表单、另一套采集引擎或第二个下载器。
5. **输出与媒体设置受控** —— 每个采集进程使用配置的受管输出根，而不是 checkout、当前工作目录或操作员任意提供的路径。集成必须显式启用锁定上游拼写为 `ENABLE_GET_MEIDAS` 的媒体开关，并通过 media-sync 自有 bootstrap 或 adapter 提供输出路径，不修改上游源文件。
6. **产物只跨越一条有界接缝** —— media-sync 只读取指定根下已经完成的输出，把它作为不可信输入处理，并关联到拥有该输出根的调度／监视任务。不能仅因 WebUI 能展示上游日志、浏览器状态或任意文件，就把它们摄取为持久 media-sync 记录。
7. **第一批保持最小范围** —— 必需实现证据只覆盖 `/crawler` 认证与路由／前缀行为、固定解释器与 checkout 选择、输出根限制、`ENABLE_GET_MEIDAS=True`、有界二维码 relay，以及上游运行时缺失时原样安全失败。测试必须确定性执行，不接触平台或 CDN。
8. **只按最小范围关闭二维码缺口** —— 锁定版本的原生路径最终调用 `PIL.Image.show()`。第一批不改变上游登录语义，只拦截 `show_qrcode`，把一张有界图片写入 attempt 级受控临时文件，仅由经认证且带 `Cache-Control: no-store` 的 endpoint 返回，并在上游 React UI 显示。完成、过期、取消或替换时删除精确临时图片。离线 relay 证据不能赋予真人浏览器扫码或登录资格。
9. **媒体服务器不是必需依赖** —— 生成并验证 Emby/Jellyfin 兼容文件夹及 NFO 不得要求连接 Emby 或 Jellyfin。只有在服务另行可用且获得授权后，才可执行服务器配置、扫描及播放验证。
10. **不得暗示真人平台资格** —— 离线路由／运行时测试不能证明二维码登录、Cookie 接受、真实采集／下载或七平台兼容。所有真人账户、七平台、CDN 及 Emby/Jellyfin 服务器行在实际执行并记录前继续为 `NOT_RUN`。
