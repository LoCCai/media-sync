Each durable job stores only a non-reversible hash of canonical work/archive roots; a different scope is rejected before reclaim or attempt mutation. Exact owner/token renewal after nominal expiry is allowed only if reclaim has not won, so renewal versus reclaim is a single-winner CAS.
